# Lab19_GitHubActions

Учебный проект на C# и .NET 8, демонстрирующий использование GitHub Actions для автоматической сборки и запуска модульных тестов.

## О проекте

Проект представляет собой простое приложение-калькулятор.

Реализованы следующие операции:

- сложение;
- вычитание;
- умножение.

Для проверки работоспособности используются модульные тесты на базе xUnit.

## GitHub Actions

В проекте настроен workflow GitHub Actions:

`.github/workflows/dotnet.yml`

Workflow автоматически запускается при `push` и `pull request` в ветку `main`.

В процессе выполнения:

1. устанавливается .NET;
2. выполняется восстановление зависимостей;
3. выполняется сборка проекта;
4. запускаются модульные тесты.
